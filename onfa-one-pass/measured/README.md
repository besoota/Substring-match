# 前処理の有無による計測結果

実行環境は Linux x86_64、AMD EPYC 7763、Python 3.12.14、Lark 1.3.1 です。研究室のサーバーとは別の環境で実行しました。

各式を `a` の1,000〜20,000文字（1,000文字刻み）で評価しました。各条件につき3回のウォームアップ後に21回を計測しました。各入力長の中央値20点から、切片を含む直線の傾きを最小二乗法で推定しました。

| 正規表現 | 1回走査の全体（µs/文字） | 行列方式の全体（µs/文字） | 行列準備後の本体（µs/文字） | 20,000文字での本体の中央値（ms） |
| --- | ---: | ---: | ---: | ---: |
| `(a*)*(?=.*b.*)` | 5.379 | 5.136 | 1.268 | 24.573 |
| `a*(?=.*b.*)` | 4.963 | 5.024 | 1.301 | 23.331 |
| `(?=.*a.*)(?=.*b.*)` | 13.027 | 12.095 | 1.269 | 23.344 |

ディレクトリの対応は、1回走査の全体が one_pass、オラクル行列を作成して本体を走査する全体が baseline、事前計算した行列を使う本体走査のみが prepared です。テキストの生成と構文解析は全方式で測定前に行いました。各ディレクトリに各反復の原データ、入力長別の集計、傾き、環境情報があります。

この入力では3式とも全位置で偽です。prepared の全1,260回の出力テープを、それぞれ同じ入力に対する従来版の出力と全境界で照合しました。空一致と一致ありの入力もテストに含みます。グラフは prepared/execution_time.png にあります。
